# GTA5RP Online Lab v1.0: техническое состояние

**Выпущено:** 2026-11-01. Основа: пользовательский `GTAV-unsigned.ipa` (iOS ARM64, P2P-порт). Сам пользовательский IPA **не публикуется** в GitHub.

## Новая функция

В экран «★ RP» добавлена кнопка **«ПОДЕЛИТЬСЯ ОТЧЁТОМ»**. Она открывает стандартное меню iOS и позволяет сохранить текстовый диагностический отчёт. Логи содержат результаты STUN, UDP, RakNet 0x05, HTTP HEAD и время. **Внешний IP может попасть в отчёт**. Перед публикацией проверь содержание. Данные не отправляются автоматически.

Исправлено отображение «MTU 576 / 1200 / 1400»: это **размеры UDP-дейтаграмм**, а не результаты измерения path MTU.

## Исследование протокола

- Настройки сервера RAGE MP: `22005` UDP+TCP, `22006` HTTP-клиентские пакеты по умолчанию; шифрование всегда включено. Источник: https://wiki.rage.mp/wiki/Server_settings.
- Открытые описания RakNet содержат `0x05 → 0x06`, `0x07 → 0x08`, `0x19` несовместимая версия, но **не описывают весь RAGE MP игрового клиента**. Источник: https://github.com/GolemOrg/RakNet/blob/master/PROTOCOL.md.
- Исследование «Reverse Engineering the RAGE:MP RakNet Protocol» (март 2026) описывает прежде всего **сервер ↔ masterlist** с расширениями защиты. Протокол не следует переносить как доказанно совместимый с **игрок ↔ GTA5RP Eclipse**: https://www.researchgate.net/publication/401661000_Reverse_Engineering_the_RAGEMP_RakNet_Protocol.
- В наших экспериментах с Eclipse не получен ответ на `0x05` при UDP-длинах 576, 1200, 1400. Тест `HEAD /` на `:22006` вернул HTTP 301 на сайт. Ни один тест не подтверждает игровую сессию или наличие загружаемого каталога.
- Google STUN на iOS отдавал тайм-аут, но Cloudflare STUN отвечал через Apple Network.framework. Поэтому **UDP в приложении функционален как минимум на одном маршруте**.

## Что нужно для настоящего мультиплеера

1. Получить **разрешённый захват своего официального RAGE MP клиента** (PCAP), изучить отличия клиентских сообщений от обычного RakNet и определить ограничения.
2. Реализовать безопасный, совместимый транспорт и криптографическое согласование только по документированным или законно полученным сведениям.
3. Реализовать авторизацию, клиентский JavaScript/CEF и игровую синхронизацию. P2P библиотека в нашем iOS порте не является клиентом RAGE MP.
4. Подтвердить игровую сессию на тестовом сервере перед заявлением о совместимости GTA5RP.

В отдельном локальном ZIP для этого этапа предусмотрен скрипт `ragemp_capture_inspect.py` (только **offline**, classic PCAP, без публикации содержимого пакетов), тесты и инструкция. Отчёты скрипта по умолчанию **не содержат IP-адресов или полезной нагрузки**. Не загружай исходные PCAP с игровыми токенами в публичный репозиторий.

## Сборка и проверка

Сборка библиотеки: GitHub Actions `Compile GTA5RP in-game menu dylib`. Архив пользовательского приложения формируется **локально** из его исходного IPA и бинарного артефакта Actions.

IPA v1.0 проверен: ZIP целый, embedded library совпадает с Actions, первоначальный `libgtacompat.dylib` и игровой ARM64 бинарник за пределами изменённого заголовка не изменены. **IPA не подписан**, установка требует переподписи. Запуск на физическом iPhone требует отдельного теста.

**Не реализовано:** официальный протокол подключения GTA5RP, авторизация и появление настоящих игроков.
