## Рабочая архитектура

```text
iPhone GTAV.app
  ├── GTA5 ARM64
  ├── libgtacompat.dylib
  │     ├── GTA Online sandbox
  │     ├── P2P session / invite code
  │     ├── LAN Bonjour _gtavmp._udp
  │     └── Internet STUN + DHT discovery
  └── остальные игровые DX11 / Metal библиотеки

GTA5RP / RAGE MP
  ├── отдельный серверный протокол UDP/TCP
  ├── клиентские JavaScript пакеты
  ├── CEF интерфейс
  └── игровая синхронизация / авторизация
```

## Что сделано
Локально перепакована **GTA5RP-P2P-Online-Lab-v0.1-unsigned.ipa** с новым названием, bundle ID и иконками. Все 6 игровых бинарников SHA-256 идентичны входному IPA. Нет изменений протокола и нет совместимости с GTA5RP. IPA в GitHub не выкладывался.

## Следующий этап
1. На двух iPhone с собственными игровыми данными проверить Host → Join по Wi-Fi, затем Join по приглашению через интернет.
2. Собрать отладочные данные для собственного P2P-режима. Не отправлять в публичный репозиторий игровые ключи/приватные данные.
3. Для доступа к GTA5RP использовать согласованную интеграцию/совместимый сетевой клиент. Не следует путать LAN/P2P с протоколом RAGE MP.
4. Для первой RP-демонстрации на собственной тестовой площадке можно реализовать отдельный разрешённый транспорт событий `spawn / move / despawn` и привязать его к игровым объектам. Упакованный бинарник не предоставляет готовых исходников и требует отдельного исследования его SDK.
