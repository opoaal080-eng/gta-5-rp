## Вывод

Это **настоящий iOS-порт игрового движка**, а не SwiftUI-оболочка. Полных игровых ресурсов GTA V в IPA нет. Порт поддерживает Script Hook V ASI и подгрузку собственных web-ресурсов игры с компьютера.

**Готового клиента протокола GTA5RP / RAGE MP в файле не обнаружено.** Наличие обычного сетевого кода GTA V не равно реализации RAGE MP; для настоящих игроков требуются авторизованная сессия, синхронизация координат, сценарии и обработка объектов.

## Практический следующий этап

1. Использовать поддерживаемую потоковую подгрузку **web build `8b0b5899ed`**, чтобы не хранить весь набор файлов на iPhone. Уменьшение кэша до 5–10 ГБ пока не подтверждено тестом.
2. В собственном тестовом окружении определить API для скриптов `.asi` и можно ли давать ему реальную сетевую синхронизацию.
3. Проверить доступ к **разрешённому серверному API координат игроков**. Публичная статистика RAGE MP сообщает только онлайн, а не положения персонажей.
4. Отдельно исследовать совместимость с существующими серверами GTA5RP. Простое копирование `client_resources` не превращает Story Mode в клиент RP.

Официальная документация: https://fivestarport.site/faq/ · https://fivestarport.site/mods/ · https://fivestarport.site/about/.

К этой публикации не прикреплён «рабочий мультиплеер»: проверена структура IPA, но **реальное подключение GTA5RP пока не реализовано**.
