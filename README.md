# GTA5RP Mobile Lab

Экспериментальный проект iOS-лаунчера и оптимизации локальных игровых файлов.

## Состояние
- Порт GTA V и мультиплеер Muguet существуют, но не совместимы с GTA5RP/RAGE MP без сетевого адаптера.
- **Полноценного GTA5RP IPA здесь ещё нет**. Требуется разрешённый доступ к игровому коду `game.wasm` и подходящим файлам игры.
- **35 ГБ → 5–10 ГБ на диске не гарантируется**. Для этого, вероятно, понадобятся потеря качества ассетов и/или сетевое стримирование с кэшем.
- Репозиторий не содержит игровых файлов.

## Исследование объёма
Перед оптимизацией запустите на своём ПК:

```powershell
python tools/audit_assets.py "D:\\GTA5-Port" --hash-duplicates
```

Скрипт создаст `asset-audit.json` и `asset-audit.md` с размером по папкам, расширениям, крупнейшими файлами, SHA-256 подтверждёнными дубликатами и расчётом экономии для 5/10 GiB. Он **никогда не меняет файлы**.

Для первого быстрого анализа можно убрать `--hash-duplicates`. Если добавляете в этот проект RP-ресурсы, анализируйте их отдельным запуском.

Отчёт можно прислать сюда. Он нужен, чтобы предметно решать, какие конкретно текстуры/аудио/карты оптимизировать, а какие нельзя трогать.

## Лицензии
Это неофициальный исследовательский проект, не связанный с GTA5RP, Rockstar Games или Take-Two. Не публикуйте проприетарный `game.wasm`, клиентские ресурсы или игровую сборку без права на распространение. Оригинальный движок [Muguet](https://github.com/c22dev/muguet) лицензирован под GPL-3.0.


## iOS-лаунчер (эксперимент)

- `apply_patch.py` добавляет экран управления RP-файлами в исходный Muguet iOS.
- `tools/RPAddon.swift` загружает ресурсы с HTTPS или импортирует папку, проверяет размеры и SHA-256.
- `tools/make_manifest.py` делает манифест из локальной папки с вашими файлами.
- `build_on_mac.sh` запускает сборку на Mac с собственным `game.wasm` или совместимым ZIP.
- `.github/workflows/build-ipa.yml` подготовлен для **приватного репозитория**, не запускается в публичном и требует секреты `GAME_WASM_URL`, `GAME_WASM_SHA256`. Ни одного игрового файла в GitHub не нужно хранить.

**Ограничение:** меню импорта ресурсов не означает, что движок уже использует эти файлы. GTA5RP/RAGE MP сеть и скрипты не реализованы. Собранная IPA на этом этапе не подключится к GTA5RP.

Сами изменения Swift требуют проверки компиляции и теста на реальном iPhone; успешная сборка здесь пока не подтверждена.

**Ограничение Five Star Port:** эта интеграция построена поверх доступного исходного кода Muguet, а не закрытого бинарника Five Star Port. Для уменьшенных файлов потребуется модифицировать проверки и способ чтения данных игровым движком, без чего Five Star Port может отклонить набор.
